# Vendored Dream World server

This directory contains the pinned `dreamworld-reawakened` server, its two
submodules, and pre-patched SWFs. The root Docker image runs it. End users
should follow the repository [README](../README.md), not start these Python
programs directly.

The upstream project is maintained at
[minibug1021/dreamworld-reawakened](https://github.com/minibug1021/dreamworld-reawakened).
Known feature limits are listed in [docs/whats-working.md](../docs/whats-working.md).
